# aio-life

Monorepo containing frontend and backend services.

## 克隆

```bash
git clone --recursive https://github.com/lys1313013/aio-life.git
```

## 更新子模块

```bash
git submodule update --remote
```

## 提交子模块更新

```bash
git add .
git commit -m "update"
git push origin main
```

## 目录结构

```
aio-life/
├── aio-life-front/    # 前端项目
└── aio-life-serve/    # 后端项目
```
