# 时迹（Time Tracker）需求方案

## 一、功能概述

时迹是 AIO Life 的核心记录引擎，以「时间块」的形式按分钟粒度记录一天的时间分配。一条时间记录（时间块）包含起止时间、分类、标题、描述，可附带运动明细或关联阅读/观影业务。

核心能力：
1. **时间块记录**：按 日 / 周 / 月 三个维度查看与操作，支持时间轴拖拽快速录入
2. **智能推荐**：根据历史记录推荐时间段与分类，降低录入成本
3. **分类体系**：公共分类（平台内置）+ 个人分类 + 对公共分类的覆盖/隐藏
4. **统计分析**：分类时长统计、与上一周期环比、多图表可视化
5. **业务关联**：时间块可关联阅读/观影记录，自动推进其状态

## 二、界面清单

共 4 个页面，均需适配暗色模式与移动端：

| 页面 | 路由 | 入口 |
|---|---|---|
| 时迹主页 | `/time/time-tracker` | 顶部菜单「时间」-「时迹」 |
| 时迹看板 | `/time/dashboard` | 顶部菜单「时间」-「看板」（展示型，只读） |
| 我的分类 | `/time/my-categories` | 顶部菜单「时间」-「我的分类」 |
| 分类管理（管理员） | `/time/category-admin` | 仅 admin 角色可见 |

### 1. 时迹主页（核心页面）

页面分上、下两大区域：

**顶部操作栏**（左侧随机格言，右侧工具栏）：
- 删除按钮（垃圾桶图标）：批量清空记录
- 分类筛选：多选，筛选后仅高亮显示选中分类的时间块
- 日期切换：左/右箭头 + 日期选择器
- 维度切换：日 / 周 / 月（`Radio.Group`）
- 视图切换：时间轴 / 卡片（偏好存 localStorage）

**左侧主区**（时间块展示，支持两种视图）：

- **时间轴视图**：
  - **日视图**：单列时间轴，左侧 24 小时刻度，右侧当日轨道；当前时刻显示实时红线指示，未来时间段用虚线 + 点状纹理区分
  - **周视图**：7 列并列，按周一为起点，每列是当天轨道
  - **月视图**：当月每天一列，横向滚动，点击列头切换选中日期
  - 时间块：按起止时间绝对定位渲染在轨道上，块内显示图标、标题（无标题时回退为分类名）、起止时间、时长；过短时间块自动压缩文字

- **卡片视图**：时间块以卡片网格展示，卡片含分类图标、分类名、时间段、时长、标题；日/周/月模式下卡片的展示方式分别为单日网格、按日分组网格。卡片带虚线点状背景表示未来时间段

**右侧统计面板**：
- **统计卡片**（正方形小卡片）：
  - 时长：当前范围记录总时长（分钟）
  - 平均：周/月模式且有分类筛选时，按「有记录的天数」计算日均时长
  - 空闲：未筛选分类时展示，日=24h、周=7×24h、月=当月天数×24h 减去已记录时长；卡片以分类颜色渐变条展示各分类占比
  - 分类时长对比卡：每个开启「卡片统计」的分类一张，展示当前周期时长与上一周期的增减（↑绿色/↓红色）
- **图表**（按维度与筛选条件动态渲染）：
  - 分类趋势折线图 `CategoryTrendLineChart`
  - 分类时长柱状图 `TimeCategoryBarChart`（日模式或未筛选）
  - 每日分类柱状图 `DailyCategoryBarChart`（周/月模式且有筛选）
  - 分类时长饼图 `TimeCategoryPieChart`（日模式且未筛选）
  - 每日统计饼图 `DailyStatsPieChart`（周/月模式且有筛选）
  - 分类堆叠面积图 `TimeCategoryStackedAreaChart`（周/月模式且未筛选）
  - 时间类型分布饼图 `TimeTypePieChart`（未筛选时，按必须/积极/休闲三色展示）

**全局浮动按钮**（右下角 `GlobalFloatBtn`）：新增时间块入口

### 2. 时迹看板

纯展示页面，无编辑入口：
- 维度切换：日 / 周 / 月（默认**周**）
- 分类筛选（多选）
- 摘要统计卡片：每个开启「卡片统计」的分类一张卡片，展示当前周期总时长 + 与上一周期环比差额（无变化显示「-」）
- 顶部展示当前所选周期文字（如「2026年第34周 (08-18 ~ 08-24)」），支持左右箭头切换周期

### 3. 我的分类

分类卡片列表，展示「已合并」的分类（公共分类 + 用户覆盖效果 + 私有分类）：
- **表格列**：拖拽手柄、图标、名称（彩色标签展示）、时间类型、卡片统计开关、操作
- **拖拽排序**：整行拖拽后调用后端批量保存排序
- **操作**：
  - 编辑：公共分类 → 进入「覆盖模式」（修改默认分类仅对本人生效）；私有分类 → 直接编辑
  - 隐藏（仅公共分类）：隐藏后归入「已隐藏分类」，可一键恢复
  - 删除（仅私有分类）：Popconfirm 确认后删除
- **已隐藏分类**：折叠面板展示，点击标签可恢复
- **新增/编辑弹窗**字段：分类名称、颜色（颜色输入框 + 取色器 + 10 色预设）、图标（24 个常用图标 + 图标库选择器 + 手动输入）、卡片统计开关、时间类型（必须/积极/休闲三选一）

### 4. 分类管理（管理员）

公共分类（平台级）的管理页面，仅 admin 可访问：
- 表格列：排序（数字）、图标、名称、时间类型、卡片统计开关、是否启用开关、操作
- 新增 / 编辑弹窗字段比「我的分类」多两项：描述、是否启用、排序（数字）
- 删除需 Popconfirm 确认，提示「删除后所有用户的覆盖设置将失效」

## 三、核心功能与交互

### 1. 时间块录入（三种方式）

| 方式 | 触发 | 说明 |
|---|---|---|
| 拖拽新建 | 时间轴空白区域按住拖拽 | 仅桌面端；松手时若时长 ≥ 15 分钟（`minSlotDuration`）则创建，自动按时间段中点调用分类推荐填充分类 |
| 按钮新增 | 点击右下角浮动按钮 | 打开新增弹窗 |
| 时间轴点按 | 移动端点按空白区域（兜底） | 同上 |

### 2. 编辑弹窗（TimeTrackerModal + TimeSlotEditForm）

点击时间块或点浮动新增按钮，弹出无标题、上下居中的编辑弹窗（宽 600px，移动端 95vw）。

**新增模式行为**（弹窗打开后自动初始化）：
1. 调用 `recommendNext({ date })` 推荐一个时间段
2. 调用 `recommendType({ date, time, previousCategoryId })` 推荐分类（`time` 取推荐时间段开始时间，`previousCategoryId` 取紧邻前一条记录的分类）
3. 表单回填推荐的时间段与分类，用户可修改后保存

**编辑模式行为**：
1. 先以传入的时间块快速回显（保证弹窗即刻撑开）
2. 异步调用 `getById(id)` 拉取详情，回填标题、描述、关联业务、运动明细

**表单字段与规则**：

| 字段 | 控件 | 规则/行为 |
|---|---|---|
| 标题 | 输入框 | 最多 50 字符；失焦时若分类为阅读/观影且标题非空，自动补全《》书名号 |
| 分类 | 分类选择器（弹窗网格） | 必选；分类命名为「运动」时展示运动明细区 |
| 开始时间 | 时间选择器 + 微调按钮 | 必选；提供 ±1 / ±30 分钟微调，长按连续调整；受相邻时间段限制（必须晚于上方块的结束时间、早于结束时间） |
| 结束时间 | 时间选择器 + 微调按钮 | 必选；`end >= start`，不得小于开始时间 1 分钟；受下方时间段开始时间限制 |
| 时长 | 时 / 分 两个可编辑数字框 | 只读联动展示，也可直接输入；结束时间随之重算 |
| 关联业务 | 关联记录选择器 | 仅当分类名称命中关联类型（阅读/观影）时出现 |
| 运动明细 | 类型选择 + 数量 | 仅「运动」分类显示；一行一明细，可增删；默认类型值与数量为空 |
| 描述 | 多行文本 | 最多 200 字符 |

**保存流程**：校验通过且与当天其他时间块（编辑时排除自身）无重叠 → 新增调 `save`，编辑调 `update` → 成功后关闭弹窗并刷新列表。若无效或重叠，`message.error` 提示「时间段无效或重叠」，不保存。

**删除入口**：编辑弹窗底部（仅已存在的时间块显示），Popconfirm 确认后调 `deleteData(id)`，成功后关闭并刷新。

### 3. 时间轴拖拽交互（桌面端）

在时间轴视图下，时间块支持：
- **移动**：按住时间块中部拖拽，实时与非自身的相邻块碰撞检测，自动限制范围为「上一个块结束时间 + 1」到「下一个块开始时间 - 1」
- **调整大小**：按住时间块上下边缘（8px 检测区）拖拽，最小时长 15 分钟，同样受相邻块限制
- 拖拽结束时仅当起止时间确实变化，才调用 `update` 保存
- 创建、移动、调整大小在拖拽过程中均避免重叠（重叠时回退原值或提示）

### 4. 批量删除

主页垃圾桶按钮 → 居中确认弹窗「此操作不可恢复」→ 点击确认：
- **日模式**：调 `deleteByDate({ date })` 删除当天全部记录
- **周模式**：对整周 7 天逐日调 `deleteByDate`
- **月模式**：删除当前选中日期的记录

### 5. 分类管理规则

- **公共分类**（平台内置，`userId = 0`）：所有用户可见，用户只能「覆盖」（改名/改色/改图标/排序，仅对自己生效）或「隐藏」，不可删除
- **私有分类**（个人）：可增删改，删除后历史时间记录的 `categoryId` 保留，分类信息展示回退为「未知」
- **覆盖实现**：用户对公共分类做修改时，生成一条 `templateId` 指向公共分类的个人记录；多个字段中只有变化字段写入覆盖记录
- **排序**：以 `sort` 权重升序，拖拽后按 `index * 10` 批量保存

### 6. 关联业务联动

时间块分类名称命中「阅读」（`relateType = 1`）或「观影」（`relateType = 2`）时，保存时间块会触发对应业务记录的状态变更：若该业务状态为「未开始」（0）则自动置为「进行中」（1）。关联业务的状态取阅读/观影模块的枚举。

### 7. 智能推荐算法

**时间块推荐 `recommendNext`**：扫描当天已有记录，找出第一个时间空隙（前一记录 `endTime + 1` 到后一记录 `startTime - 1`）；若无空隙则从末尾开始。当天推荐结束时间取当前时刻，非当天默认 30 分钟。结果限制在 0–1439 分钟内。

**分类推荐 `recommendType`**（输入：日期、分钟数、可选紧邻前一分类）：
1. 计算参考日期：周一 → 上周五（-3天）；周六 → 上周日（-6天）；其他 → 前一天
2. 查参考日期同一时间段（`start <= time <= end`）的记录分类，命中即返回
3. 未命中则统计历史上该时间段各分类频次，区分工作日/休息日，取最高频
4. 若推荐分类与紧邻前一分类相同，做去重干预：
   - 先预测后续行为：历史上紧跟在「前一分类」之后最常出现的分类（同一天内无缝衔接）
   - 再降级：该时间段最高频分类（排除前一分类）
   - 仍无则允许连续相同
5. 返回分类 ID（可能为空）

## 四、数据模型

### 时间记录（time_record）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 雪花 ID |
| userId | long | 用户 ID |
| categoryId | long | 分类 ID |
| date | date | 日期（YYYY-MM-DD） |
| startTime | int | 开始时间（分钟，0–1439，闭区间起点） |
| endTime | int | 结束时间（分钟，0–1439，闭区间终点） |
| duration | int | 时长 = endTime - startTime + 1，服务端计算 |
| title | string | 标题（≤50） |
| description | string | 描述（≤200） |
| relateType | int | 关联类型（1=阅读，2=观影） |
| relateId | long | 关联业务 ID |
| isManual | int | 是否手动添加 |
| 基础字段 | — | 逻辑删除 `is_deleted`、createTime/updateTime 等 |

### 分类（time_tracker_category）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | long | 雪花 ID |
| userId | long | 用户 ID（0 = 公共分类） |
| templateId | long | 覆盖记录指向的公共分类 ID（空 = 私有或公共） |
| name | string | 分类名称 |
| color | string | Hex 颜色 |
| icon | string | Iconify 图标名 |
| timeType | int | 时间类型：1=必须，2=积极，3=休闲 |
| isTrackTime | int | 是否参与「卡片统计」 |
| isEnabled | int | 是否启用 |
| sort | int | 排序权重 |
| description | string | 描述（管理员维护） |

**合并规则**（前端展示）：公共分类 + 各用户的覆盖记录（override）+ 私有分类合并展示；`is_deleted = 1` 的覆盖记录视为「隐藏该公共分类」。

### 运动记录（exercise_record）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 雪花 ID |
| userId | long | 用户 ID |
| timeId | string | 关联的时间记录 ID |
| exerciseTypeId | string | 运动类型（对应字典 `exercise_type`） |
| exerciseCount | int | 次数/数量 |
| exerciseDate | date | 运动日期 |

一条时间记录可含多条运动明细；编辑时先删后插保证一致。运动明细在编辑弹窗「运动」分类下维护。
