## 二 页面字段

列表按下表顺序展示 10 项业务字段，可以保留序号、结果和详情入口。现有昵称、浏览器、功能名称、功能项和创建时间保留在详情中；功能点由功能名称与功能项组合，避免重复列。

| 列名 | API 字段 | 展示与取值规则 |
| --- | --- | --- |
| 用户 ID | `userId` | 来自服务端鉴权身份；以字符串显示、复制、筛选，禁止转为 number |
| 用户名 | `username` | 操作时的登录账号快照；不是昵称 `nickname`；后续改名不回写历史 |
| 功能点 | `functionName`、`functionItem` | 如「待办 · 新增」；使用现有菜单标题与操作类型快照。无页面来源时使用服务端接口功能定义，未定义则「接口操作 · 查询」等 |
| 请求地址 | `requestPath` | 复用已有接口路由模板，如 `/todo/{id}`；不含 `/api` context-path、协议、域名、查询串或 fragment；具体路径参数在脱敏参数详情中查看 |
| 请求方式 | `requestMethod` | HTTP 方法大写，如 `GET`、`POST`、`PUT`、`PATCH`、`DELETE` |
| 请求参数 | `requestParams`（详情） | 查看图标按钮，`aria-label="查看请求参数"`；点击后按需加载脱敏参数，NULL 显示「未采集」，`{}` 显示「无参数」 |
| 请求时间 | `requestTime` | 服务端接收时间，显示 `YYYY-MM-DD HH:mm:ss.SSS`；统一使用 `Asia/Shanghai` |
| 处理时间 | `durationMs` | 非负整数毫秒；如 `128 ms`、`0 ms`，不能把 0 当成缺失；超过 1000 ms 可同时提示秒数，原始毫秒值可查看 |
| 请求 IP | `ipAddress` | 请求来源 IP，支持 IPv4、IPv6；仅采用服务端可信代理规则解析后的地址 |
| 服务器 IP | `serverIp` | 实际处理该请求的后端实例 IP；容器部署允许为容器或 Pod IP，不取浏览器、网关或客户端传入的 IP |

历史记录的请求方式、参数、耗时和服务器 IP 显示「未采集」；新旧记录的请求地址统一展示已有路由模板。历史请求时间退回 `createTime`，标注「历史记录时间」，不补造毫秒精度。账号等快照缺失显示 `—`，不根据当前用户资料伪造历史值。

## 三 使用流程与权限

### 查询与筛选

- 仅管理员可进入页面、查询列表、查看参数和导出；由后端校验 `admin`，不能只隐藏菜单。沿用已有菜单与二级锁规则。
- 保留默认最近 8 个自然日、重置、分页与账号模糊查询；默认每页 20 条，可选 50、100，服务端上限 100。清空日期仍可查询全部时间。
- 本期沿用日期与账号筛选，不增加其他筛选项。
- 日期按请求时间筛选；历史记录使用 `createTime` 参与日期筛选。日期结束值包含整天，内部采用次日零点的开区间；按有效时间及 ID 倒序。
- 查询、重置、筛选变化后回到第一页；旧响应不能覆盖新筛选结果。不自动轮询列表。

### 参数详情与导出

点击参数图标打开居中弹窗，按路径参数、查询参数、请求体分组显示已采集的脱敏 JSON。复制只能取得脱敏后的内容；NULL 统一显示「未采集」，`{}` 显示「无参数」，无需展示具体未采集原因。

列表不携带参数正文，每行提供查看入口，点击时查询单条详情。详情请求使用按钮或弹窗局部 loading，失败可重试，不刷新整表。筛选和分页刷新保留已有内容及区域高度，首屏、空态、错误重试和深浅主题按共同 UI 规则验收。桌面、平板和手机 Web 使用水平滚动或详情展开，保证这 10 项均可访问。

保留按已提交筛选条件「导出全部」。导出包含这 10 项与结果；请求参数为与详情相同的脱敏 JSON，未采集与无参数按页面规则处理。按开始导出时的最大 ID 固定上界，分批读取，避免并发新增无限延长导出。延续 UTF-8 BOM、CSV 引号与公式前缀转义，ID 按文本处理。

移动端业务请求与 Web 请求使用同一后端采集规则；首期展示入口为已有 Web 管理页面，不新增移动端原生管理页。

## 四 采集规则

### 范围与身份

延续当前已通过认证并进入业务 Controller 的 HTTP 请求范围，包含查询与写入、成功与失败，也覆盖通过 API Key 认证的 HTTP 业务请求。身份必须从服务端已验证上下文读取，不使用请求参数中的 `userId`。

沿用会话信息、权限码、未读消息心跳、文件预览与下载等排除规则；不新增 OPTIONS、静态资源、健康检查、Prometheus、拦截器拒绝的请求、后台定时任务或直接调用 Service 的 MCP Tool 记录。登录、登出仍归入 `ACCESS`，保持现有访问日志行为，参数正文不采集。

现有操作日志查询与导出仍可记录为一次普通管理员操作，但其参数一律跳过，不嵌套保存返回的日志或参数详情，不因写入日志再触发采集。

功能点优先使用服务端稳定定义；沿用 `X-Page-Path` 匹配菜单只作页面上下文展示，不把客户端传来的标题当作可信操作类型，也不能用于授权。用户名和功能点存快照，日志查询不依赖当前用户或菜单仍然存在。

### 时间与结果

在请求进入后端的早期过滤器记录接收时间和单调时钟起点。仅在请求符合采集范围后生成日志；正常返回、业务失败及异常均结束计时。耗时截至 Controller 调用完成或抛出异常，不含日志落库、客户端网络时间、下载传输或异步后台任务；不宣称是完整网络响应耗时。异步和流式响应首期不承诺后台完成耗时。

采用单调时钟计算耗时，毫秒值可为 0，不能使用两个墙上时钟时间相减以免系统校时产生负数。应用、数据库会话统一时区，时间字段不是异步落库时间。保留现有 `create_time` 审计含义，不将其重新定义为实际持久化时刻。

`ApiResponse.code == 0` 才判定业务成功；业务失败码或异常为失败。HTTP 200 不能单独决定业务成功。请求 IP 不直接信任任意 `X-Forwarded-For`；服务器 IP 读取后端实例的本机地址，获取失败保存 NULL。

### 故障隔离

沿用独立事务落库，业务回滚仍保存失败记录。参数解析、脱敏或日志落库失败不得覆盖原业务响应、异常或事务结果。参数采集失败或无法确认脱敏安全时，仅保存其他日志字段，`request_params` 保存 NULL。

采集过程有大小和遍历上限；不为日志二次消费请求流、不无限缓冲文件、不序列化 Servlet 对象。默认继续使用有界的同步采集与现有独立事务，不承诺零日志延迟。服务端错误日志只记录元数据和故障原因，不通过降级日志重新输出原始敏感参数。

## 五 参数采集与脱敏

引入参数展示后，更新当前「不保存请求参数」规则为「只保存允许采集且已经脱敏的参数快照」。旧版仍不保存参数；访问日志继续不保存正文。

1. 路径、查询和 JSON 或表单正文分别采集，不把查询串拼回请求地址。重复查询参数保留数组，嵌套对象与数组递归处理，参数内的业务 ID 按接口契约保留字符串。
2. 按服务端内置安全字段采集；新增或未覆盖接口默认跳过参数，不直接序列化全部 DTO。字段敏感规则优先于白名单，匹配不区分大小写并归一化下划线与连字符。
3. 密码、二级密码、密码盐、Token、Cookie、Authorization、验证码、API Key、第三方凭证、签名和密钥内容一律移除或替换为 `[REDACTED]`，嵌套对象同样执行。不得采集请求头全集。
4. 密码库、银行卡密文与安全码、绑定凭证、密码修改与重置等敏感接口整体跳过正文；自由文本如备忘内容、反馈正文和个人健康内容默认不入白名单。URL 类型字段需额外清除嵌入凭证，否则跳过该字段。
5. 文件上传仅允许记录白名单中的非敏感元信息，如文件类型、大小；不存文件内容、Base64、二进制或未经规则许可的文件名。不支持的正文格式、加密正文或未经允许的超大请求跳过正文。
6. 脱敏后的单条 JSON UTF-8 最大 32 KiB，单个字符串最大 2000 个字符，嵌套最大 8 层；遍历最多 1000 个节点。请求 Content-Length 超过 64 KiB 时不采集参数；仅读取 Controller 已绑定的白名单字段，不缓存或重读原始请求流。任一限制超出时，整条参数快照保存 NULL，其他日志字段正常保存；不保存截断片段，也不将非法 JSON 写入数据库。

| `requestParams` | 含义 | 页面展示 |
| --- | --- | --- |
| 有内容的 JSON 对象 | 已按规则采集，可能含脱敏占位值 | 格式化 JSON |
| `{}` | 确认请求本身无参数 | 无参数 |
| NULL | 历史未采集、规则跳过、超限或采集失败 | 未采集 |

参数对象按 `path`、`query`、`body` 分组，只保存白名单允许采集的内容，不另存采集状态或省略标记。只有确认请求本身无参数时保存 `{}`；存在参数但均未获准采集时保存 NULL。不提供查看原始参数或关闭脱敏的管理员入口。

## 六 接口契约

沿用 `GET /api/system/logs/operation` 与 `GET /api/system/logs/operation/export`；新增 `GET /api/system/logs/operation/{id}` 按需查询详情。详情仅能读取未逻辑删除的 `OPERATION` 记录，其他日志类型、无效 ID 或不存在记录按系统错误约定返回。

查询参数沿用 `page`、`pageSize`、`username`、`startDate`、`endDate`，不增加高级筛选参数。

列表返回 `ApiResponse<PageResp<...>>`，成功结构为 `{ code: 0, message: null, data: { items: [], total: 0 } }`。保留现有字段，增加下列字段，详情额外返回 `requestParams`：

```ts
interface OperationLogFields {
  id: string;
  userId: string | null;
  username: string;
  functionName: string | null;
  functionItem: string | null;
  requestPath: string | null;
  requestMethod: string | null;
  requestTime: string | null;
  durationMs: number | null;
  ipAddress: string;
  serverIp: string | null;
  success: boolean;
  createTime: string;
}

interface OperationLogDetail extends OperationLogFields {
  requestParams: Record<string, unknown> | null;
}
```

新增字段明确返回 null，不能沿用 `NON_NULL` 导致客户端依赖的字段消失；既有字段保留原有序列化兼容性。分页 `total` 遵守现有 `number | null` 契约。`durationMs` 后端使用 `Integer`，输出 JSON number；ID 使用 Long 并输出字符串。Entity、列表 VO、详情 VO 与查询 DTO 分开，不能直接返回 Entity。

## 七 表结构与实施顺序

详细字段、索引、SQL 草案和历史兼容见[操作日志数据库结构设计](../design/operation-log/database-design.md)。扩展既有 `sys_activity_log`，新增 5 个可空字段，保留 `ACCESS` 与全部历史数据。

实施时先完成结构迁移和预检，再部署后端采集、列表与详情，最后更新前端列与筛选。历史缺失字段保持 NULL；不从 HTTP 路由、当前用户资料或当前服务器地址反推历史值。请求参数只从新版采集上线后产生。

本期不提供日志修改、删除、清空或自动清理入口，不改变既有保留期限；后续如设计清理策略，应单独明确保留天数和执行规则。本目录 SQL 保留为结构摘录；后端全量结构、增量脚本、升级计划校验和、表结构文档、Entity 和 Mapper 已同步，部署以[后端升级说明](../../aio-life-server/docs/数据库升级验证.md)为准。

## 八 验收标准

| 场景 | 预期 |
| --- | --- |
| 新增、查询、修改、删除接口 | 每次符合范围的请求生成一条记录，10 项字段按规则可查看 |
| 大整数 ID、用户改名、菜单改名或删除 | ID 不失真；账号与功能点保持历史快照 |
| 带路径变量、重复查询参数、嵌套 JSON | 请求地址展示路由模板，具体路径变量在脱敏参数中查看；参数分组准确、不影响原请求 |
| 敏感接口、未知接口、嵌套密码与 Token | 白名单与敏感规则生效；数据库、详情、CSV、错误日志均无原文 |
| 无参数、0 ms、超限 JSON、文件上传、脱敏失败 | 无参数保存 `{}`，超限或失败保存 NULL，0 ms 正常显示，业务响应保持原样 |
| 成功码 0、HTTP 200 业务失败、异常与业务回滚 | 结果正确，失败记录保留；日志故障不改变业务结果 |
| IPv4、IPv6、可信反向代理、伪造 XFF、多实例 | 请求 IP 与服务器 IP 含义正确，不采用客户端伪造值 |
| 跨日、毫秒时间、旧记录、混合版本部署 | 时区一致，日期边界正确；历史与旧实例缺失字段展示未采集 |
| 筛选、分页、导出时新增日志 | 筛选一致、旧响应不覆盖新状态、导出有边界、参数按需加载 |
| 非管理员、越权详情、跨日志类型详情 | 后端拒绝，不能通过直接请求绕过菜单或二级锁 |
| 首屏、空态、错误重试、已有数据刷新 | loading 可感知且高度稳定；覆盖手机、平板、桌面与深浅主题 |

验证记录与本地测试边界见[后端日志说明](../../aio-life-server/docs/操作和访问日志.md)。部署环境仍需执行迁移、结构预检与真实账号联调。
