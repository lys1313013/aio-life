# 会员维护需求方案

## 一、业务概述

记录个人当前持有的所有会员/订阅服务，追踪到期时间，避免忘记续费或续费遗漏。

常见场景：视频会员（爱奇艺、腾讯视频、B 站）、音乐会员（网易云、QQ 音乐）、购物会员（京东 PLUS、淘宝 88VIP）、云盘（百度网盘、iCloud）、学习工具（WPS、坚果云）、游戏订阅（XGPU）等。

核心能力：会员 CRUD、到期倒计时与状态展示、到期提醒。

## 二、前端展示字段

### 1. 列表页（卡片/网格视图）

每条会员以卡片展示，核心是"看它还剩多久"。

| 字段 | 展示形式 | 说明 |
|------|----------|------|
| icon | emoji 图标 | 会员图标，卡片左上角 |
| name | 主标题 | 会员名称 |
| category | 标签 | 分类标签（视频/音乐/购物等） |
| provider | 副标题 | 平台/服务商 |
| expiryDate | 日期 + 倒计时 | 到期日期 + 剩余天数（如"2026-09-01 · 剩 26 天"） |
| status | 状态徽标 | 生效中 / 即将到期 / 已过期，颜色区分 |
| autoRenew | 角标 | 自动续费标记（AUTO） |

**排序规则**：生效中的按到期日期升序（最早到期排最前），已过期的置底。

## 三、数据库表设计

### 1. 新增表 `membership_record` — 会员记录表

| 字段 | 类型 | 空 | 默认 | 说明 |
|------|------|-----|------|------|
| id | BIGINT | 否 | 雪花 ID | 主键 |
| user_id | BIGINT | 否 | | 用户 ID |
| name | VARCHAR(100) | 否 | | 会员名称 |
| category | VARCHAR(50) | 否 | other | 分类：video/music/shopping/cloud/study/game/other |
| provider | VARCHAR(100) | 是 | NULL | 平台/服务商 |
| icon | VARCHAR(50) | 是 | NULL | emoji 图标 |
| color | VARCHAR(50) | 是 | NULL | 卡片背景色 class |
| start_date | DATE | 是 | NULL | 开通日期 |
| expiry_date | DATE | 否 | | 到期日期 |
| price | DECIMAL(10,2) | 是 | NULL | 支付金额 |
| billing_cycle | VARCHAR(20) | 是 | NULL | 计费周期：month/quarter/year/once |
| auto_renew | TINYINT | 否 | 0 | 是否自动续费：0-否 1-是 |
| account | VARCHAR(100) | 是 | NULL | 绑定账户 |
| remind_days | INT | 否 | 7 | 到期前提醒天数 |
| note | VARCHAR(500) | 是 | NULL | 备注 |
| is_deleted | TINYINT | 否 | 0 | 逻辑删除：0-未删除 1-已删除 |
| create_time | DATETIME | 是 | NULL | 创建时间 |
| update_time | DATETIME | 是 | NULL | 更新时间 |
| create_user | BIGINT | 是 | NULL | 创建人 |
| update_user | BIGINT | 是 | NULL | 更新人 |

**索引**：

| 索引名 | 字段 | 类型 |
|--------|------|------|
| idx_user_id | user_id | 普通索引 |
| idx_expiry_date | expiry_date | 普通索引（按到期排序/查询） |

**说明**：

- `status` 不落库，由后端按 `expiry_date` 实时计算，保证到期后状态自动变化。
- `category` 复用现有用户字典能力，可自定义扩展分类；暂不新增独立分类表。
- 建表脚本放 `aio-life-server/sql/1_init_table/`，命名 `2026-08-06_create_membership_record.sql`。

## 四、API 设计

后端新增 `membership` 模块（`top.aiolife.membership`），沿用现有分层（api/service/mapper/pojo）。

| 方法 | 地址 | 说明 |
|------|------|------|
| GET | /membership/list | 会员列表（含计算后的 status、remainingDays） |
| GET | /membership/stats | 统计：生效中/本月到期/已过期数量 |
| GET | /membership/{id} | 会员详情 |
| POST | /membership | 新增会员 |
| PUT | /membership | 修改会员 |
| DELETE | /membership/{id} | 删除会员 |

### 状态计算规则

| status | 条件 |
|--------|------|
| expired 已过期 | expiry_date < 今天 |
| expiring 即将到期 | expiry_date - 今天 ≤ remind_days |
| active 生效中 | 其余 |

---

## 五、到期提醒（P1）

复用现有通知渠道基础设施（`notification_channel_config` + 通知偏好 + Outbox 异步投递）：

- 每日定时任务扫描次日到 `remind_days` 内到期的会员；
- 发送内容：会员名称 + 到期日期 + 剩余天数；
- 用户通过通知偏好控制是否接收、提前几天提醒。
