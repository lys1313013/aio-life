## 修正内容

- 页面只保留一层边距，消除MobilePage、业务root、导航栏连续缩进；自有滚动页使用同一配置。
- 统一卡片、图表、表单、工具栏、弹窗间距。并排字段compact/stretch，按钮底边对齐，避免margin和gap累加。
- library/anniversary/衣柜网格列宽与间隔引用同一变量，配置变化时一起调整；首页网格的cell内边距有配套补偿。
- 关系详情不渲染空字段占位；确认按钮不再强制顶部对齐；统计值字体直接施加到text节点保证可读。
- `spacing.json`是唯一数值来源，脚本生成`_spacing-tokens.scss`和`spacing.scss`；样式引用SCSS变量/公共类，测量代码读取同一JSON。无需运行时CSS变量支持。
- 主仓及Mobile的AGENTS.md已固化规则；新增生成物漂移与失效引用检查。
