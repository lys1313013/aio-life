# 首页微信读书「阅读统计」卡片需求

> 状态：Web 与 Mobile 源码已接入。实现入口及历史验证见 §14；提交、部署和平台验收按对应版本单独核验。
> 适用范围：Web（`aio-life-front`）与 Mobile（`aio-life-mobile`，含 H5、微信小程序、App）首页。

## 1. 背景与目标

首页现有两张微信读书卡片：`overview.read`（今日阅读时长与连续阅读天数）和 `section.weread`（最近阅读书架）。两者回答"今天读了多久"和"最近读了什么"，但没有阅读节奏。用户希望在首页直接看到本周阅读趋势，并能切换月、年观察长期习惯。

目标：

- 新增一张独立卡片，用柱状图展示当前自然周／月／年的阅读时长分布。
- 同时给出周期总时长、日均时长和较上一周期同期的变化，让用户不打开业务页也能判断趋势。
- 卡片可单独启停、排序、恢复默认，遵守现有首页卡片与权限体系。

非目标：不替换、不合并 `overview.read` 与 `section.weread`；不在首页提供历史周期翻页、日期选择或"累计"视图，这些继续由微信读书业务页承担。

## 2. 卡片定义

| 项 | 取值 | 说明 |
| --- | --- | --- |
| `cardKey` | `section.weread-stats` | 新标识，不与 `overview.read`、`section.weread` 复用 |
| 分组 | `section` | 内容卡片分组，独立请求 |
| 标题 | 阅读统计 | 标题行右侧放周／月／年切换 |
| `visualKey` | `weread` | 复用微信读书菜单的图标与颜色，不新增图标资产 |
| 默认启用 | 是 | 新卡片默认展示；用户已保存的启停设置优先 |
| 默认顺序 | 紧随 `section.weread` | 便于和最近阅读相邻；排序仍走现有卡片设置 |
| 数据来源 | 微信读书官方 Gateway `/readdata/detail` | 只读，不写入、不同步第三方数据 |

- 卡片目录维护在服务端 `HomeCardCatalog`，客户端不硬编码；启停、排序、恢复默认复用 `/home/cards` 现有接口，不新增首页设置项。
- 本卡不新增数据库表、字段或 Flyway 迁移；不新增菜单，图标与颜色引用现有微信读书菜单。
- 未绑定微信读书 Key、菜单不可用、二级锁未解锁时不展示卡片内容；已绑定但本期无阅读时保留卡片、日期与基线，并显示空态提示（见 §7）。

## 3. 展示与布局

### 3.1 卡片结构

```
┌────────────────────────────────────────────┐
│ [图标] 阅读统计                     周 | 月 | 年 │
│ 本周 3 小时 20 分                            │
│ 日均 28 分钟           比上周 ↑ +16%         │
│  ▁  ▃  ▅  ▂  ▇  ▄  ▁                      │
│  一   二   三   四   五   六   日             │
└────────────────────────────────────────────┘
```

从上到下固定为四部分：标题行（含粒度切换）、汇总区两行、柱状图、横轴标签。卡片内不出现图例、y 轴刻度、刷新按钮或"查看更多"按钮。

### 3.2 汇总区

| 指标 | 文案示例 | 规则 |
| --- | --- | --- |
| 周期总时长 | 本周 3 小时 20 分 / 本月 12 小时 / 本年 48 小时 | 前缀随粒度变化：本周、本月、本年；值为周期内全部时长 |
| 日均时长 | 日均 28 分钟 | 总时长 ÷ 周期内已过天数（含今天），四舍五入到分钟 |
| 同期变化 | 比上周 ↑ +16% / 比上月 ↓ -8% / 比上年 新增 / 比上周 — | 与上一周期对齐区间对比（见 §4）；箭头随方向，颜色使用中性文本色，不使用红色警示。`—` 表示两侧都为 0 |

- 总时长为卡片主数值（约 20px／桌面 22px），日均与变化为次要信息（约 12px）。
- 变化百分比按整数展示；上一周期为 0 且本周期大于 0 时显示"新增"；两侧都为 0 时显示"比上周 —"之类的占位，不显示 `∞` 或 `100%`。
- 变化与日均同处第二行，常驻显示"比上周／比上月／比上年"；窄屏空间不足时允许自然换行。计算仍按 §4 的同期范围，悬浮提示或读屏保留完整同期语义与日期范围。

### 3.3 柱状图

| 粒度 | 柱子数量 | 横轴标签 | 柱值 |
| --- | --- | --- | --- |
| 周 | 7（周一至周日） | 一、二、三、四、五、六、日，全端完整显示 | 当天阅读分钟数 |
| 月 | 当月天数（28–31） | 仅显示 1、8、15、22、29 日（存在时），其余留空 | 当天阅读分钟数 |
| 年 | 12（1–12 月） | 1…12（不带"月"），全端完整显示 | 当月阅读分钟数 |

- 不显示 y 轴与刻度线，柱高按周期内最大柱值等比缩放；保留一条 1px 基线。
- 柱宽自适应，周视图最大 36px，月／年最大 24px，最小 2px；顶部圆角 4px；柱间距 8–12px（周／年）或 1–2px（月）。月视图的窄柱不显示柱顶数值。
- 柱色按用户指定参考图采用顶部的纯蓝色 `#34a6ff`，不使用渐变或叠加透明度；卡片图标仍引用菜单配置。零值不绘制柱体或弱色底座；保留日期位置、标签与交互区域，日期序列连续可读。
- 交互提示：Web 悬停／键盘聚焦显示提示"M月D日 · N 分钟"（年视图为"M月 · N 小时 M 分"）；Mobile 轻触柱子显示同样的卡内浮层，浮层绝对定位，不改变卡片高度与柱状图布局；再次轻触空白或切换粒度关闭。零值显示"未阅读"。
- 周期全为 0 时保留完整日期标签、基线，不绘制柱体，在图表区域叠加不占布局的空态："本周还没有阅读记录"（粒度对应文案），不隐藏卡片或改变图表高度。
- 图表容器提供可访问摘要，例如"本周阅读 3 小时 20 分，日均 28 分钟；周一 35 分钟……"；柱子本身不承担跳转或编辑。

### 3.4 时长与日期格式

| 场景 | 规则 | 示例 |
| --- | --- | --- |
| 不足 1 分钟 | 显示"不足 1 分钟" | 40 秒 → 不足 1 分钟 |
| 小于 1 小时 | 显示"N 分钟"，四舍五入 | 35 分 20 秒 → 35 分钟 |
| 大于等于 1 小时 | 显示"N 小时 M 分"，分钟为 0 时省略"0 分" | 3 小时 20 分、2 小时 |
| 零值 | 显示"0 分钟"；图表提示"未阅读" | — |
| 日期 | 客户端按 `Asia/Shanghai` 展示；周内为"M月D日" | 11月3日 |

时长统一以秒为接口单位，展示时四舍五入到分钟；接口不再返回格式化文案，避免两端格式漂移。

## 4. 数据口径

- 周期：自然周（周一 00:00 至周日 24:00）、自然月（1 日至月末）、自然年（1 月 1 日至 12 月 31 日），时区固定 `Asia/Shanghai`；周从周一开始，与微信读书官方周报一致。
- 数据源：Gateway `/readdata/detail`，`mode` 分别为 `weekly`、`monthly`、`annually`；`baseTime` 取周期起点当天 00:00 的 Unix 秒（年取 1 月 1 日）。返回的 `readTimes` 以周期内日期（年视图为月份）的本地零点时间戳为键、阅读秒数为值；缺失日期按 0 补齐，重复键求和。
- 未来日期：当前周、月、年中尚未到来的日期按 0 展示，不显示负值，不绘制零值柱体，保留对应日期位置。
- 周期总时长 `totalSeconds`：全部桶值之和，含未来 0 值。
- 已过天数 `elapsedDays`：今天在周期内的序号（含今天）；周视图周一为 1、周日为 7，月视图为当天日期，年视图为年内第几天。
- 日均 `dailyAverageSeconds = round(totalSeconds / elapsedDays)`；不按"有阅读的天数"计算，避免少读几天时日均虚高。
- 同期对比：优先取上一周期相同天数区间。
  - 周：上周一至上周同日（今天周五则对比上周一至上周五）。
  - 月：上月 1 日至上月同日；上月天数不足时取至上月最后一天，按实际区间累计，不补 0。
  - 年：上年 1 月 1 日至上年同月月末。年统计只有月粒度，按整月对比；当前月为不完整月，变化仅作趋势参考。
  - 因月末天数差异，周、月两侧天数可能相差 1–3 天；对比值只用于趋势提示，不要求与当前周期等长。
- 当前周期不提供历史浏览，因此 `elapsedDays` 始终为"截至今天"；上一周期只用于计算对比值，不展示其柱图。
- 示例：今天为 2026-11-06（周五），本周从 2026-11-02（周一）开始，已过 5 天；对比区间为 2026-10-26（周一）至 2026-10-30（周五）。

## 5. 接口契约

### 5.1 请求

```http
GET /home/sections/weread-stats?granularity=week
```

- `granularity` 必填，取值 `week`｜`month`｜`year`，不接受其他值或缺省；客户端始终显式传入。
- 接口只返回当前周期，不接受 `baseTime`、日期区间或 `overall`；历史浏览由微信读书业务页承担，避免首页卡片状态与网关参数膨胀。
- 新增 Query DTO 后运行 `python3 scripts/generate-api-contracts.py` 同步两端字段白名单，禁止手改生成文件。

### 5.2 响应

```json
{
  "code": 0,
  "message": null,
  "data": {
    "connected": true,
    "granularity": "week",
    "periodStart": "2026-11-02",
    "periodEnd": "2026-11-08",
    "elapsedDays": 5,
    "buckets": [
      { "key": "2026-11-02", "label": "周一", "seconds": 2100 },
      { "key": "2026-11-03", "label": "周二", "seconds": 1800 },
      { "key": "2026-11-04", "label": "周三", "seconds": 0 }
    ],
    "totalSeconds": 7200,
    "dailyAverageSeconds": 1440,
    "previousPeriodStart": "2026-10-26",
    "previousPeriodEnd": "2026-10-30",
    "previousTotalSeconds": 6600,
    "refreshInterval": 600
  }
}
```

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `connected` | boolean | 当前用户是否已绑定可用 Key；为 `false` 时客户端隐藏卡片，其余字段仍返回当前周期与 0 值 |
| `granularity` | string | 回显请求粒度 |
| `periodStart` / `periodEnd` | string `yyyy-MM-dd` | 当前周期首尾日期，含首尾 |
| `elapsedDays` | number | 已过天数（含今天），≥1 |
| `buckets` | array | 周 7 项、月当月天数项、年 12 项；`key` 为 `yyyy-MM-dd`（年视图为 `yyyy-MM`），`label` 为周一…周日／1…31／1月…12月，`seconds` 为整数秒；客户端将周、年 `label` 简化为“一…日”“1…12”，提示日期保留完整单位 |
| `totalSeconds` | number | 周期总秒数，整数 |
| `dailyAverageSeconds` | number | 日均秒数，四舍五入后的整数 |
| `previousPeriodStart` / `previousPeriodEnd` | string `yyyy-MM-dd` | 同期对比区间，含首尾；年视图为上一年同月月末 |
| `previousTotalSeconds` | number | 同期对比区间总秒数，整数 |
| `refreshInterval` | number | 自动刷新间隔，单位秒，本期固定 600 |

- 所有秒数使用 JSON 数字，不使用字符串；日期使用 `yyyy-MM-dd`；本接口没有 ID 字段。
- 变化百分比由客户端根据 `totalSeconds` 与 `previousTotalSeconds` 计算并格式化，服务端不返回展示文案。
- 服务端返回完整周期桶，缺失日期补 0，保证客户端无需再推算日历。

### 5.3 未绑定与错误

| 场景 | 服务端 | 客户端 |
| --- | --- | --- |
| 未绑定 Key／已解绑 | 返回 `connected: false`，不调用 Gateway | 隐藏卡片，不显示空态或错误 |
| Key 失效（401/403） | 业务错误："微信读书连接已失效，请重新授权" | 卡内错误 + "去设置"入口，跳转 `/record/weread` |
| 频率限制或网关异常（429/5xx/超时） | 业务错误："微信读书暂时不可用，请稍后重试" | 保留已有内容，卡内局部重试；不把错误当空数据 |
| 二级锁／菜单权限未解锁 | 按现有统一鉴权拒绝，不返回业务数据 | 不请求、不渲染数据，与 `section.weread` 一致 |
| 参数非法 | 参数错误，`code` 非 0 | 记录错误并重试；不静默改成默认粒度 |

- 错误响应沿用 `{ code, message, data }`，HTTP 200 不等于成功。
- 不向客户端透传网关错误正文、Key 或内部地址；日志中不记录 Key。

### 5.4 缓存与刷新

- 服务端复用现有 `WereadReadCache`：按连接 scope 与请求参数缓存 5 分钟，同参数并发读取合并，失败冷却 30 秒；不新增第二套微信读书缓存或凭证读取路径。每次请求最多访问两次 Gateway（当前周期与对比周期）。
- `refreshInterval` 返回 600 秒；前端据此建立本卡独立调度。首页定时刷新只查询统计，不触发第三方同步、写入或解锁弹窗。
- 返回首页的本地时效检查沿用微信读书最近阅读的 5 分钟口径；离开首页、应用后台或组件卸载时停止调度并使旧响应失效。

## 6. 交互与状态

- **粒度切换**：标题行右侧"周｜月｜年"分段控件，默认周。切换只请求本卡当前粒度，不触发整页刷新或其它卡片；选择按账号保存在客户端本地（如 `home:wereadStats:granularity:<userId>`），刷新、返回首页、重新打开后恢复，不写入服务端数据库。
- **切换反馈**：保留旧柱图、汇总与卡片高度，在图表区叠加局部 loading；禁止整卡骨架闪烁。快速连续切换用请求版本号丢弃旧响应，旧响应不得覆盖新选择。
- **切换失败**：保留原内容与高度，在图表区显示失败与重试；重试沿用当前选择，不静默回退到周。
- **空白点击刷新**：点击卡片顶部空白区域仅刷新本卡当前粒度，加载中不重复触发，有可访问名称并支持键盘；标题跳转、粒度切换、柱子提示不触发刷新。
- **标题跳转**：点击标题进入微信读书业务页 `/record/weread`；不因跳转丢失本卡已加载内容。
- **柱子点击**：只显示提示，不跳转、不编辑；无数据时点击空白关闭提示。
- **首次进入**：先加载卡片设置与权限，启用且有权限时请求；单卡失败不阻塞其它卡片。
- **整页刷新**：Mobile 下拉刷新、Web 首页刷新入口按现有规则更新本卡；返回首页按 5 分钟时效与失败状态补刷。
- **启停与排序**：关闭后不发请求；重新启用后按需加载。排序、恢复默认沿用现有卡片设置，新卡片参与 `section` 分组排序。

## 7. 加载、空态、错误与权限

- **首次加载骨架**：按真实结构预留标题行、两行汇总、柱状图区和横轴，高度与展示态一致（Web 桌面 280px、平板 250px；Mobile 手机 240px、平板 250px、桌面 280px）；骨架柱数量与当前粒度一致，不统一套用固定行数。
- **刷新已有内容**：保留旧内容与高度，局部 loading 不参与布局，不挤动标题、粒度控件与后续卡片。
- **已绑定但周期无阅读**：保留卡片，保留日期与基线、不绘制零值柱体，并显示空态文案"本周／本月／本年还没有阅读记录"，不显示错误。
- **未绑定**：隐藏卡片，不显示空态；绑定后首次回到首页或手动刷新时出现。
- **错误**：首次失败显示卡内重试；已有内容失败保留内容并局部重试。Key 失效显示"去设置"，不使用"重试"掩盖授权问题。
- **权限与二级锁**：仅查询当前用户有权且已解锁的微信读书数据；本卡同时受首页与微信读书菜单的二级锁约束，未解锁时不请求、不渲染，服务端执行同样校验。首页卡片设置中的图标与颜色继续引用微信读书菜单配置。
- **数据安全**：接口不暴露 Key、网关原始响应或无关统计；只返回卡片需要的聚合字段。

## 8. 跨端实现要求

### 8.1 Web

- 复用微信读书业务页已有的 ECharts 封装与 `useEcharts`（`aio-life-front/apps/web-antd/src/views/my-hub/weread/dashboard.vue`），不新增图表依赖；卡片组件放在首页卡片目录，按现有 section 卡片模式接入。
- 三列桌面 280px、双列平板 250px 卡高与其它卡片对齐；单列窄宽度下允许图表压缩，但不截断横轴标签与汇总数字。图表区自适应剩余高度（桌面约 140px、平板约 110px），不截断横轴与汇总。
- 深浅主题使用现有 token；柱子颜色取菜单主色，不硬编码业务色值。hover、focus、tooltip 与粒度控件的键盘操作可用。
- 请求去重、旧响应失效、局部 loading、失败重试与生命周期处理沿用首页现有 section 组件模式。

### 8.2 Mobile

- 不引入图表库：用 `view` 按百分比高度渲染柱子，控制微信包体；不为本卡新增重量依赖。柱子点击提示使用卡内绝对定位浮层，不依赖 hover。
- 手机单列卡片高度按内容自适应，上限 240px；平板 250px、桌面 280px，与首页现有 `cardHeightLimit` 一致；图表区约 92px（手机）、100px（平板）、130px（桌面），横轴标签不换行。
- 字号使用 `src/styles/typography.json` 的语义角色，间距使用 `src/styles/spacing.json`，不复制数值；深浅主题、H5／微信／App 三端一致。
- 支持卡片顶部空白局部刷新与整页下拉刷新；提示交互不依赖新窗口或 hover。
- 新增组件与逻辑进入现有分包策略，不因本卡导致主包超出预算；包体检查按现有 `scripts/weixin-package-policy.json` 执行。

### 8.3 共同

- 卡片目录、权限、空态、刷新与响应式规则以本文及 [首页功能说明](首页功能说明.md) 为准，两端不各写一套业务口径。

## 10. 验收要点

- **口径**：周从周一开始；月、年边界正确；未来日期补 0；日均按已过天数；同期对比区间对齐（含跨月、跨年、闰年；上月天数不足时取月末）；缺失日期补 0 且桶数量完整。
- **接口**：`week`／`month`／`year` 三种粒度返回字段与类型正确；未绑定返回 `connected:false` 且不访问 Gateway；Key 失效、429、超时、参数非法的错误码与文案符合本文；同一请求并发合并、5 分钟缓存生效；服务端二级锁拒绝未授权读取。
- **Web**：三档视口（手机、平板、桌面）与深浅主题下卡片高度、柱宽、标签、汇总数字正常；周／月／年切换保留高度并正确去重；粒度按账号恢复；空白刷新、标题跳转、tooltip、键盘操作可用；骨架、空态、首次失败、刷新失败、未绑定、锁未解锁场景符合 §7；关闭卡片后不发请求。
- **Mobile**：H5、微信编译、模拟器／真机与 App 分别验证；无图表库依赖且包体不超预算；柱状图触摸提示、横轴、高度规则、局部与整页刷新、粒度恢复、空态与错误符合本文；深色主题与平板宽度无过宽、过疏或裁切。
- **证据边界**：源码核查、Mock 数据、真实后端、H5、微信编译／模拟器／真机、App 与发布分别记录，不互相替代；未实际执行的平台不能记为通过。

## 11. 不在本期范围

- 首页历史周期浏览（上一周／上一月／上一年）、日期选择与"累计"视图；这些继续在微信读书业务页完成。
- 阅读天数、连续阅读天数、读完本数、书籍排行、单本明细与阅读笔记；后续如需展示再单独立项。
- 与 `overview.read`（今日阅读）或 `section.weread`（最近阅读）合并、替换或共享卡片位置。
- 微信读书数据落库、快照、导出、目标联动与通知。
- 非微信读书数据源（手动阅读记录 `section.reading`）的统计。

## 12. 待确认与风险

- **空数据是否隐藏**：本文采用"已绑定即保留卡片并显示空态"，避免用户找不到功能；如产品希望无阅读时隐藏，只需调整客户端展示条件，不影响接口。
- **月视图可读性**：31 根窄柱在手机宽度下的点击命中与标签密度需要走查；必要时只保留每 7 天标签与触摸提示，不减少数据。
- **同期对比 vs 整周期对比**：本文选择同期（对齐区间），避免周初查看时"较上周下降"的误读；如需改为整周期对比，需同步改文案与测试。
- **网关字段**：`readTimes` 以秒为单位、`annually` 按月返回键值，依据现有 Web 看板实现推断；实施前用真实账号复核，若形状变化需先调整解析与契约，不能静默按 0 处理。
- **频率限制**：每次请求最多两次 Gateway 调用，叠加 5 分钟缓存与 600 秒刷新；如真实账号仍触发 429，优先延长缓存与刷新间隔，而不是去掉对比指标。
