# 身体档案

个人中心提供「身体档案」，集中查看当前身体数据，优先服务健身时的围度查阅。每个用户仅一份当前档案，编辑覆盖原值，不提供历史记录、趋势、打卡或目标体重。页面采用黑白灰人体轮廓，适配手机、平板、桌面及深浅主题。

- 顶部展示身高（cm）、体重（kg）、BMI、体脂率（%）。BMI 由当前身高体重自动计算并保留一位小数，不手动填写、不保存；任一来源缺失时不计算。体脂率仅手动填写实测结果，不由其他数据推测。
- 人体周围展示肩宽、胸围、上臂围、前臂围、腰围、臀围、大腿围、小腿围，单位 cm。男女轮廓分别绘制，性别仅在编辑中选择，不在展示页出现切换控件。轮廓仅为位置示意，不根据体重自动重塑。
- 四肢围度可以标记测量侧别（左/右），上臂可标记自然放松/屈臂收缩；这些表示当前数据的测量口径，不创建历史序列。首期每项围度保存一个当前值，不同时保存左右两份数值。
- 「穿戴尺码与身体长度」默认折叠，包含上衣、裤子、鞋码、腿内侧长。鞋码默认展示「42 码」，编辑时区分欧码、中国码（毫米）、美码、英码，不自动换算。衣柜单件衣物尺码不随档案修改。
- 所有字段选填，留空可清除；未填展示「—」，不得当作零或示例数据。点击指标可局部编辑，右上角编辑可修改完整档案。编辑居中、保存按钮有 loading，失败保留输入，成功使用服务端返回值更新本页。
- 初次读取失败禁止编辑，提供重试；后续刷新保留旧内容和布局。离页、退出或切换账号后的旧响应不得写回。数据仅按登录用户读写，不接受客户端指定归属。

## 接口与持久化

`GET /body-profile` 返回当前档案；未创建返回可空字段及 `version: 0`。`PUT /body-profile` 完整替换，所有可空业务字段用显式 null 清除，并提交读取到的数值 version；成功返回完整新档案与递增版本，冲突返回 HTTP 409，禁止旧表单覆盖其他终端的更新。

`user_body_profile` 的 `user_id` 唯一；沿用 BaseEntity 审计与逻辑删除字段。ID 为字符串，数值指标及 version 为 JSON number，BMI 不落表。请求不包含 ID、BMI、审计或用户身份。仅提供当前档案读写接口。

旧库部署前执行后端 `sql/1_init_table/2026-10-20_body_profile.sql`；新库已合入全量结构，升级计划同步维护。Web 入口为个人中心「身体档案」标签；移动端为「我 → 身体档案」，页面及资源归入独立业务分包。
