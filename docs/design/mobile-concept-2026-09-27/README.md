# AIO Life 移动端概念方案

本方案于 2026-09-27 基于当时的前端路由整理，属于历史设计建议，效果图数据均为示例。当前导航与功能范围见[移动端 README](../../../aio-life-mobile/README.md)，本方案不表示当前实现或验收状态。

底部固定 5 个主菜单：**今日 / 时迹 / 任务 / 生活 / 我的**。新增按钮不占导航位；在需要创建内容的页面展示 `+`，目录和个人设置页不展示。

| 主菜单 | 内容 |
| --- | --- |
| 今日 | 正在计时、今日待办、当天数据摘要、用户自选快捷入口 |
| 时迹 | 时间轴、计时与补记、时间看板；分类配置通过设置进入 |
| 任务 | 待办、目标，以页内切换组织 |
| 生活 | 全部生活功能，按记录与成长、财务与物品、关系与纪念分组 |
| 我的 | 个人资料、账号安全、我的分类、快捷入口、外观、同步、消息、反馈 |

生活目录：

- 记录与成长：阅读记录、微信读书、运动、视频观看、闪念、笔记、活动、里程碑、荣誉。
- 财务与物品：财务中心（概览、收入、支出、账单导入、银行卡）、会员、衣柜、设备墙、密码管理。
- 关系与纪念：纪念日、关系图谱、编程看板（GitHub、LeetCode、CSDN）。

“生活”承担完整功能目录；“今日”的常用入口由用户选择，示意图中的阅读、运动、财务、衣柜仅表示已配置示例，不作为新用户默认配置。

管理员的用户、菜单、字典、操作日志等低频管理功能继续以桌面管理端为主，不占普通用户底部菜单。移动端入口仍应沿用现有权限和菜单锁。

交互建议：今日的 `+` 打开居中的快捷选择面板（时迹、待办、收支、闪念、运动、阅读）；时迹和任务页的 `+` 直接新增当前类型。界面使用图标操作、短导航名称与轻量列表，支持深浅主题。手机底部导航，平板可改为侧边导航并保留相同五个分区。
