# 手机端分类思维导图候选方案

- 日期：2026-11-11。
- 状态：待讨论，按用户本次要求新增的三个交互候选方案；尚未采纳，也不是正式 UI 契约。
- 对应实现：当前仅为本目录的静态 HTML，不修改 Web、Mobile、后端，不对接现行业务数据。
- 与正式客户端的差异：使用虚构分类和浏览器本地存储，不提供账号同步、业务关联和服务端持久化。
- 保留原因与待确认项：比较自由画布、纵向分类树、逐层聚焦三种手机操作方式；选定交互和 Markdown 范围后再决定正式实现，未采纳或被实现替代后删除原型并清理索引。

打开 [对比入口](index.html)，或分别打开 [自由画布](canvas.html)、[分类树](tree.html)、[逐层聚焦](focus.html)。HTML 与同目录的 `app.css`、`app.js` 一起使用，无外部 CDN 或第三方运行依赖，可离线打开。

三个方案分别保存数据。支持点选分类、新增下级／同级、改名、删除、撤销／重做、Markdown 双向编辑、导出 `.md`、切换深浅主题。自由画布可滚动、缩放和展开／收起节点；分类树可折叠；聚焦版通过卡片进入下层、路径返回上层。刷新后从当前浏览器存储恢复；不支持多设备同步。本地文件地址下的存储能力以浏览器为准，不可用时显示“暂未保存”。

Markdown 当前支持分类结构：唯一 `# 根分类`，下方通过 `- 分类` 和每级两个空格的缩进表达层级；也接受 `*`、`+` 列表标记。最多 500 个节点、30 层分类，每个名称最多 80 个字。不支持正文段落、富文本、任务状态和多根文档，格式不符会标明错误并保留编辑器内容。只有有效分类结构会同步和保存，Markdown 无效时关闭页面会请求浏览器提示。

本地服务预览（主仓库执行）：

```bash
python3 -m http.server 5196 --bind 127.0.0.1 --directory docs/prototypes/life-mindmap
```

然后访问 `http://127.0.0.1:5196/`。用手机访问时，需要由你选择能从手机访问的本机监听地址；默认预览只绑定本机。
