## 公共图片与 ESA 缓存

- 统一入口为 `GET /api/public/images/{fileId}.{ext}`，不含具体业务名称；支持 PNG、JPEG（`.jpg`）、WebP、GIF、BMP。服务端地址由 `AIO_LIFE_SERVER_BASE_URL` 生成，生产环境需使用经过 ESA 的外部 API 地址。
- 当前只公开两类图片：已保存到未删除公共卡面模板的图片，以及 `is_public=1` 且被所属用户当前 `avatar_file_id` 引用的头像。保存为公共模板即发布底图；停用只禁止新选用，不撤回图片。私人卡面、其他附件、未绑定临时图片和逻辑删除文件均不能由这个入口读取。MinIO 桶无需改为公共。
- 模板列表/详情/选项返回 `publicUrl`，银行卡返回 `coverTemplatePublicUrl`，头像沿用 `avatarUrl` 字段返回新入口。Web/Mobile 直接展示服务端 URL；旧后端缺少新字段时仍兼容原鉴权路径，临时编辑预览继续鉴权。
- 图片按真实内容验证格式、字节和像素上限；URL 后缀不匹配实际格式时返回 404。成功响应返回真实图片 MIME、`nosniff`、ETag，以及 `Cache-Control: public, max-age=86400, s-maxage=2592000`。错误响应返回 `no-store`。GET 支持条件请求，HEAD 不返回图片正文。
- 换图必须生成新文件 ID 和新对象路径，不覆盖原对象；前端重新读取业务信息后获得新 URL，无需等待旧 URL 缓存过期。旧图在源站不再可读，但已缓存副本不会立即撤回；删除或撤回需要清理 ESA，浏览器缓存可能持续至过期。
- 2026-10-04 只读核对的现有 ESA 规则 `CacheStaticAssets` 覆盖所有路径下的 `css/js/png/json/jpg/svg/webp`，边缘忽略源站策略固定缓存 1 个月，浏览器遵循源站，查询参数全部保留并排序。新入口的 PNG/JPG/WebP 会命中该规则，无需新增规则；GIF/BMP 使用未被其他规则覆盖时的默认图片缓存策略。本次代码变更不修改 ESA 控制台。
- 部署后验收：匿名连续 GET 同一个已发布图片 URL，确认真实图片响应及 `x-site-cache-status: HIT`；确认换图返回新 URL；私人/临时图片不能从公共入口获取。代码测试或本地 H5 验证不代表已部署或线上 ESA 已命中。
