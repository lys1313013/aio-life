# 今日时迹卡片设计

本说明从 front 的 `docs/superpowers/specs/2026-06-16-today-time-tracker-design.md` 提取并按 2026-10-09 源码更新，供 Web 与 Mobile 共用。整体刷新与配置规则见 [首页功能说明](首页功能说明.md)，本页维护时迹的数据和交互要求。

## 数据与时间

- 当天日期使用用户本地日历日；读取分类与该日期完整时迹，不能只获取前五条后把它们当作当天全部记录。
- `startTime`、`endTime` 是从零点起算的分钟整数，不是 Unix 时间戳。时长为 `endTime - startTime + 1`；23:10–23:33 为 24 分钟。
- 明细按 `startTime` 倒序。展示开始时刻、紧凑时长、分类路径，颜色来自对应分类；名称太长可省略，详情／编辑仍保留完整值。记录 ID 始终是字符串。
- 时间轴使用全部记录，位置为 `startTime / 1440`，长度为闭区间时长 `/ 1440`；环图按分类汇总完整分钟数，不能因显示条数限制漏算。
- 最新记录末分钟后的边界为 `endTime + 1`；距上次记录时长为当前分钟减去该边界，不取负值。无记录时只显示新增图标。

## 展示与布局

- 保留竖向 0–24 小时时间轴、分类环图及可独立滚动的明细。手机也保留明细与点击编辑入口，不能仅桌面展示。
- 首屏明细约五行是布局容量，**不是数据截取上限**；第六条及之后通过卡内滚动查看。少量明细避免永久大块留白，长分类名不撑宽内容。
- Web 当前卡片为手机 240px、平板 250px、桌面 280px；Mobile 当前同类高度上限为 240 / 250 / 280px，多列和单列策略以对应客户端实现为准。断点不要求复制框架数值，但手机、平板、桌面均需核验。
- 首次 loading 使用时间轴、环图、明细对应的占位结构；有内容或已加载空结果时刷新，保留原布局及滚动区域，使用不占布局的局部反馈。
- 今日无数据时仍显示卡片与新增入口，读取失败使用错误和重试状态，不伪装成“暂无记录”。

## 点击、刷新与编辑

- 标题进入时迹页面，顶部空白区域刷新当前卡片。Mobile 保留整页下拉刷新；顶部空白刷新与标题跳转已补齐，平台验收边界见 [核查清单](mobile-migration/home-card-audit.md)。
- 右上“距上次记录时长 ＋”打开共用 `TimeRecordEditor` / Web 时迹编辑器；首页新增默认今天。点击明细加载完整记录后编辑，详情失败禁止提交。
- 时长文字每分钟本地更新；可见首页每 300 秒重新读取当天数据，跨日立即查询新日期。离页／后台停止请求，回来检查日期与时效，旧日响应不得覆盖新日。
- 保存、删除后仅更新时迹及受影响运动区域和运动概览，保留运动明细、阅读／观影关联字段；不无条件刷新所有首页卡片。
- 长按排序与点击编辑、点击刷新、卡内滚动互不触发；拖动后不误开编辑弹窗。

## 验收

- 空、单条、五条、超过五条及长分类名；所有记录均可查看，汇总时长不受可见条数影响。
- 闭区间、午夜、跨日请求竞争；标题跳转、新增、明细编辑、删除、冲突校验与失败恢复。
- 300 秒数据刷新、每分钟本地时钟、后台暂停及恢复去重分别验证；不能以时长文字变化证明接口自动刷新。
- 手机／平板／桌面、深浅主题，延迟请求下比较首次 loading、内容、空态、失败重试及已有内容刷新高度与后续卡片位置。
- 实现状态与已执行的动态验收见核查清单，模拟接口、微信编译与真机结果分别记录。
