# 首页（Dashboard）功能需求文档

## 1. 核心数据概览 (Overview)
- **功能说明**：顶部统计卡片，展示各模块的核心指标（如任务、时间、运动等）。
- **交互设计**：
  - 支持长按（PC端鼠标按住 / 移动端长按）触发快捷操作（如快速唤起时迹记录弹窗、运动记录弹窗）。
  - 支持点击卡片静默刷新数据。
  - 页面可见时支持定时自动刷新，切换后台时自动暂停定时器以节省性能。

## 2. 今日时迹 (Time Tracker)
- **功能说明**：展示今日的时间分配和追踪分析。
- **展示逻辑**：仅在当日存在时迹记录时才渲染展示，无数据时隐藏。
- **交互设计**：点击标题可手动刷新今日数据。

## 3. 快捷导航 (Quick Nav)
- **功能说明**：提供系统内高频常用模块的快速跳转入口。

## 4. 关注的待办 (Watched Tasks)
- **功能说明**：集中展示用户在任务管理中星标（关注）的待办事项。
- **展示信息**：优先级标签、任务内容、关联主任务名、起止时间。
- **交互设计**：
  - 可直接在列表中点击复选框标记完成。
  - 点击任务文本可打开编辑弹窗。
  - 无数据时提供占位图和操作引导。

## 5. 固定的闪念 (Pinned Thoughts)
- **功能说明**：展示用户星标固定的闪念笔记。
- **交互设计**：
  - 点击单条闪念可直接跳转至闪念功能模块。
  - 无数据时提供操作引导。

## 6. 运动汇总 (Exercise Summary)
- **功能说明**：按天和运动类型展示近期的运动数据统计。
- **交互设计**：
  - 点击标题“运动汇总”可跳转至运动菜单界面。
  - 右上角提供简洁的单箭头刷新按钮，用于局部刷新运动数据。

## 7. GitHub 最近提交 (GitHub Commits)
- **功能说明**：展示用户近期的 GitHub 代码提交动态。
- **展示逻辑**：仅在用户系统内成功绑定 GitHub 账号后才渲染展示。
- **交互设计**：
  - 点击用户图标/链接可跳转至 GitHub 个人主页。
  - 详细提交信息限制单行截断（超出显示省略号），悬浮显示完整信息。
