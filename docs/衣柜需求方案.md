# 衣柜需求方案

## 一、字段设计

### 1. 衣物基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| name | string | 衣物名称 |
| categoryId | string | 分类 ID |
| color | string | 颜色 |
| brand | string | 品牌 |
| season | array | 适用季节：[春, 夏, 秋, 冬] |
| purchaseDate | date | 购买日期 |
| price | number | 购买价格 |
| photos | array | 照片 URL 列表 |
| size | string | 尺码 |
| memo | string | 备注 |

### 2. 分类体系

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| name | string | 分类名称 |
| icon | string | 图标 |
| parentId | string | 父分类 ID（一级/二级分类） |
| sort | number | 排序 |
| userId | string | 用户 ID（支持自定义分类） |

---

## 二、功能模块

### 1. 衣物管理

- **添加衣物**：拍照/相册选择，填写信息
- **编辑衣物**：修改任意字段
- **删除衣物**：支持批量删除
- **搜索衣物**：按名称、颜色、品牌等搜索
- **筛选衣物**：按分类、季节、颜色等筛选

### 2. 分类管理

- **系统预设分类**：上衣、裤子、裙子、鞋子、配饰等
- **自定义分类**：
  - 添加自定义分类名称
  - 支持二级分类（父分类 + 子分类）
  - 修改分类名称/图标
  - 删除分类（衣物自动归入"未分类"）
  - 调整分类顺序

### 3. 衣柜展示（设备墙模式）

- **网格视图**：以卡片形式展示衣物
- **分类筛选**：点击分类标签筛选
- **季节筛选**：春/夏/秋/冬快捷筛选
- **颜色筛选**：按颜色快速筛选
- **拖拽排序**：长按拖拽调整顺序

### 4. 数据统计

- **衣物数量**：总数量、各分类数量
- **季节分布**：各季节衣物占比
- **价格统计**：总价值、平均价格

### 5. 衣橱提醒

- **换季提醒**：季节变化时提醒整理

## 四、技术栈

- **前端**：Vue 3 + Vben Admin
- **后端**：Spring Boot 3.3.10 + Java 21
- **数据库**：MySQL
- **存储**：MinIO
